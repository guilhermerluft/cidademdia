# ADR 0001 — Reconstrução greenfield

## Decisão

A nova plataforma será criada integralmente do zero.

Não serão reutilizados código, componentes, CSS, banco MongoDB, models, rotas, APIs ou páginas do sistema atual.

A estilização dos dashboards das contas atuais é somente uma referência visual. Os dashboards da nova aplicação serão reimplementados com componentes novos.
